## Goal

Build a **Minimum Viable Model (MVM)** for sports betting prop prediction. The purpose is *not* to immediately place bets. The purpose is to learn the full pipeline end-to-end on the smallest possible scope, validate whether the model has edge against historical lines, and only then scale.

---

## Scope Constraints (intentionally small)

- **One sport** (to be selected by operator — likely NBA, NFL, or MLB)
- **One stat / prop type** (e.g., NBA points, NFL receiving yards, MLB strikeouts)
- **One platform's line structure** (Sleeper, PrizePicks, Underdog, or a traditional sportsbook)
- **One model type** to start (likely Poisson or simple regression, depending on stat distribution)

We will expand only after the MVM is working and validated.

---

## Required Components

1. **Data ingestion layer**
   - Source: free stats API or scraper (e.g., nba_api, nfl_data_py, pybaseball)
   - Pull historical player game logs for the chosen stat
   - Clean and structure into a usable dataframe

2. **Feature engineering**
   - Rolling averages (last 5, 10, 20 games)
   - Opponent-adjusted metrics (defense rank vs. position)
   - Home/away splits
   - Rest days
   - Pace / usage context where applicable

3. **Model**
   - Start with Poisson distribution for count stats (points, strikeouts, receptions)
   - Or linear/logistic regression for continuous/binary outcomes
   - Output: probability distribution for the stat, not just a point estimate

4. **Line comparison module**
   - Input: sportsbook/app line for the prop
   - Compare model's implied probability vs. line's implied probability
   - Output: edge percentage and recommended action (bet over / bet under / pass)

5. **Bankroll / sizing layer**
   - Kelly Criterion calculation (fractional Kelly — 0.25x — for safety)
   - Unit sizing based on edge magnitude

6. **Backtesting harness**
   - Run the model against historical lines (if available) or against historical outcomes with synthetic lines
   - Report: hit rate, ROI, CLV proxy, max drawdown, sample size
