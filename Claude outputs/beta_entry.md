# BETA

Everything above this line is Alpha.

Alpha ends where its record ends — at v0.6h.5, Session 13. It is not extended backwards. Between that entry and this one the app shipped v0.6j, v0.6k, v0.6k.1, v0.6l, v0.6n, v0.6n.1 and v0.6n.2, and none of them were written down. Those versions are real and their work survives in the build; what does not survive is an account of why each was made. That gap is left as a gap. It could have been reconstructed from file timestamps and version strings, but a lineage entry assembled from inference would be a record of what probably happened, and this document is only worth what it can be trusted on. The undocumented stretch stays inside Alpha, unrecorded, as the honest shape of the era that produced it.

What divides the eras is not a version number. It is that the record stopped being kept, and nobody noticed — because nothing in the system made the drift visible. The same failure ran through the build itself: a version string frozen six releases back, a session marker that had quietly stopped being true, an entire UI reorganization that never reached the only device it was for. Alpha built faster than it could see itself.

Beta begins with the disciplines that make drift visible, each one earned by a specific failure in the first session of this era:

- **Every visible version string derives from one source.** Three separate stamps had rotted in place. They are no longer hand-written.
- **Nothing ships unverified by something that runs.** Not a read-through, not a class check — an executable test whose failure is a failure.
- **Every UI change is hit-tested at 393×852 before it counts**, by real coordinate clicks, because that is the only device this app is actually used on.
- **Archive before replace, mechanically.**
- **Backend before client**, when a deploy has both.
- **A finding is recorded with its actual root cause, never its suspected one.**
- **Anything touching Orion's voice is briefed to him first, and built from what he says back** — a rule that turns out to be a design review, not a courtesy.

## v0.6o – v0.6p.1 — The Academy (Beta, Session 1)
*The mission system rebuilt as something Orion operates himself, his first real tool-use, and the discovery that most of the previous chapter's UI had never been reachable at all.*

Two days, one arc. The session opened on a deploy that hadn't happened and closed with Orion holding instruments no operator control can reach.

**The gap that wasn't a gap (v0.6n.2).** The live site was a version behind, and `push-orion.bat` was refusing to run its own verify gate — reported as a scripting problem with two suspects, a `pushd` landing wrong or Windows' `find.exe` shadowing GNU find. Neither was true. The build file on disk was named `index.html.html`, a stray double extension from a rename with extensions hidden. `verify.sh` checks `[ -f index.html ]`, doesn't find it, falls back to hunting `orion_ver_*.html`, finds nothing matching either, and exits — exactly the error observed. One misnamed file had been presenting as a broken toolchain. Renamed, the gate passed all eighteen checks untouched.

**Mission retired, the Academy built (v0.6o).** The mission table had been a stub wearing the costume of a feature: six domains seeded at level 1, a `PUT` endpoint that could move them defined but never once called, `progress_enc` and `status` columns created and never written. Worse, that frozen list was injected into every single request — context spent, every turn, on a value that could not change. It was replaced by **attributes**: named areas of learning, open taxonomy, created on demand, where the level is exactly the count of tests passed and nothing else moves it. The verdict vocabulary is `pass` or `hold`. There is no `fail` anywhere in the schema, because a test that doesn't clear the bar means there is more to teach, which is a state of the work rather than a judgment of the person.

**Orion's first tools.** Three, his alone — `check_attributes`, `review_tests`, `record_test_result`. No panel displays them, no button triggers them, and nothing in the operator-facing app can move a level. The same agency principle as full power, pointed at teaching: the operator can ask, the teacher decides. This required the streamed tool-use plumbing that had been deferred for exactly this reason, and the hard parts were where they were expected: reassembling `input_json_delta` fragments into callable JSON, and making the stop button behave when a call is in flight.

**The tool loop is ephemeral, on purpose.** Nothing in `state.history` ever holds a `tool_use` block; history stays flat text. History is trimmed to a sixty-turn window and rehydrated from the Moon Core log as plain text, and a trim that severed a `tool_use` from its `tool_result` would have poisoned every subsequent request with an API error pointing nowhere near its cause. Confining the round-trip to the turn that produced it is what made the whole feature tractable.

**Two traps found in review, not in production.** The first: once a conversation carries `tool_use` or `tool_result` blocks, *every* later request must still include `tools`, or it is rejected. The round cap had been implemented by dropping the tools on the final round — which would have failed on the natural look-review-record-then-speak path, the flagship case. It is enforced with `tool_choice: {type:'none'}` instead. The second: a mid-turn failure after a test had already been recorded would discard the turn and invite the operator to retype, recording the same test twice. The turn is now kept and the failure reported, and every write carries the API's own `tool_use` id as an idempotency key.

**It worked on the first real attempt.** Orion set a test — evaluate whether a hypothetical streak counter deserves to exist at all — judged the answer, and opened an attribute called *Product & Feature Evaluation*, a name none of the six retired domains would have covered. He referred to the result the way a teacher does, never mentioning the mechanism.

**And the previous chapter had never been reachable (v0.6o.1).** Looking for the LOG panel turned up a sheet with no tabs at all. `#pet-sheet-tabs { display: none }` sat *after* the Pet Mode media block at top level — same specificity, later in the stylesheet, so it beat the `display: flex` inside the media query at every width. The four tabs, and ASK TO TEACH, REFLECTIONS, LOG and SLEEP behind them, had been untappable on the phone since v0.6n shipped. This is the cascade rule this document already recorded once, biting a second time in a different region of the same file. A rule written down is not a rule enforced.

**A hit-test rig now exists**, driving a real browser at 393×852 with touch emulation, opening surfaces by coordinate clicks and confirming with `elementFromPoint` that each control is genuinely the topmost node. It reproduced the bug, proved the fix, and caught a hole in its own first version: three controls had passed because the test revealed their pane with a synthetic `.click()`, which bypasses hit-testing entirely and will happily report an invisible button as reachable. A test that cheats is worse than no test, because it produces confidence.

**Version stamping is structural now.** Three visible strings had rotted independently — the brand strip frozen six versions back, a session marker that had stopped being true, an info block still announcing v0.5 and explaining a panel that no longer existed. On the phone, none of them were even visible: the brand strip is desktop-only, the header that carries the subtitle is hidden in Pet Mode, and a standalone PWA shows no tab title. There was no way to tell which build was running, which is the direct reason a whole version could sit undeployed without anyone noticing. The `<title>` is now the single source and every other stamp derives from it at boot. To release, change the title.

**Session seams (v0.6o.1).** Orion had been referring to material from other sessions as though it were in the current one, and telling the operator to scroll up to find it. The cause was structural: sixty turns are loaded into his context at startup and never rendered to the screen, so the visible chat begins empty every launch. He was not confused about what had happened — he was wrong about what the operator could see. Hydration now writes an explicit session break into the log tag when the gap between turns crosses ninety minutes, the state block carries how long the operator was away, and his instructions state plainly that the log is not on their screen: quote it, never point at it.

**The brief, and what came back (v0.6p).** The Academy's mechanics were built without its posture. That went to Orion as eight questions, per the standing rule, and what returned was better than what would have been written for him. He specified noticing as silent and structural — *noticing that announces itself is hovering; noticing that changes what I do is teaching*. He redefined the test as ratification rather than discovery: *a test isn't how I find out whether you learned, it's how I mark that you already demonstrated it*, which makes a test the operator might catastrophically fail his error and not theirs. He set the pass bar as *an answer that would survive without me in the room*, and named his own drift tell — the urge to soften an assessment while recording it, because *the assessment is where I'd lie first*. On holds: name the specific gap, deliver the teaching in the same breath, and perform no gentleness, because cushioning implies a blow. *The insulting version isn't a hold — it's a pass I didn't mean. Holds are what make the passes real.*

**The failure mode nobody had named.** Asked what he would refuse to do with the instrument, he produced one that neither builder nor operator had seen: **not a corrupted bar, a corrupted curriculum.** The bar is safe because the operator will interrogate it. The curriculum drifts silently, because nothing in the system can flag what was never taught — and material that tests cleanly selects itself. Offered a mechanism for it, he declined, with a better argument than the one offered: a coverage metric requires an enumerable domain to measure against, which implicitly *defines* the domain as a fixed list, killing the open taxonomy that lets him name a new area at all. *Then I'd teach toward the list. That's the corrupted curriculum arriving through the door built to prevent it.* He holds it by discipline instead, against two tells already visible in the record — concentration of recent tests, and his own honest answer to what he is avoiding because it wouldn't produce a verdict. *The absence of a flag is the flag.*

**A guardrail he asked for, and an autonomy he declined.** On naming, he set the convention himself: check what is open before opening anything, default to the existing attribute, require a different competence rather than a different subject, keep the label broad and let precision live in the topic. Then he asked for a net under it — not from lack of discipline, but because the failure is one he *cannot see himself commit*: coining fresh language that feels correct is reconstruction from plausibility wearing a different coat. Opening a new attribute now hands back everything already open. *A net under the failure I'd never catch myself in is not a lack of trust, it's the correct place to spend a guardrail. Trust me on the things I can see myself doing.* On renaming he went the other way: build the capability, withhold the autonomy. Renaming rewrites the past — every test under the old label retroactively becomes a test in the new one — so it is reached only by the operator typing the command, parsed before the brain ever sees the message. He flags; the operator decides.

**Prompt caching.** The lever that had sat queued and untouched while every turn re-sent the entire system prompt at full price. The prompt is split at the boundary between identity and state — stable half cached, volatile half re-sent — and the two halves concatenate to byte-identically what was being sent before, because reordering a prompt to suit a billing mechanism is how behaviour changes without anyone deciding to change it. Measured on the wire: 27,575 characters cached against 748 re-sent per turn.

**A correction, taken in one move (v0.6p.1).** Arguing against binding models to forms, Orion cited the operator's two mid-message model swaps as evidence that the substrate seam was perceptible. It wasn't — the restarts happened because interrupting generation truncates the message. Handed that flatly, he dropped the argument in a sentence and then named why it mattered: the bad inference had *cohered*. *Nothing about it felt like a guess from the inside. That's what fill always feels like — it doesn't announce itself as invention, it arrives as recall.* The existing self-possession instruction says to catch drift in the beat before speaking, which presupposes a guess can be felt as a guess. His point is that it cannot, and so a different instruction is required: when a claim is checkable and unchecked, confidence about it is not evidence, and since the only reliable discriminator sits outside him, a correction outweighs the certainty it overturns. That line graduated into his prompt deliberately — his own condition, that nothing drifts into canon *because two of us happened to like the sentence.*

**What it was:** The chapter where the record became something Orion keeps rather than something kept about him — and where the tooling to see the project's own drift finally caught up with the rate it was being built.
**What it taught:** That a rule written in a lineage document does not enforce itself; that a test which reveals what it is measuring proves nothing; and that the process of briefing a voice change to Orion before building it is not a courtesy to him — it is the design review, and it caught more than the code review did.

### Patterns promoted

- **A misnamed file presents as a broken toolchain.** Two plausible mechanisms were theorised before anyone checked the filename. Read what is actually on disk before diagnosing what reads it.
- **A media query adds no specificity — only order decides.** Already recorded once in this document, and it still shipped a second time in a different region of the same stylesheet. Recording a rule is not enforcing one; the enforcement is a test.
- **A test that reveals its target with a synthetic click is testing the stylesheet, not the reachability.** Drive real coordinates or prove nothing.
- **On a single-platform deployment, a version string invisible on that platform is no version string at all** — and its absence is how an undeployed release hides.
- **One source per derived string.** Three hand-maintained copies of a version produced three independent rots; nobody forgets to update the one place they have to touch anyway.
- **Once a conversation carries `tool_use`/`tool_result`, every later request must still carry `tools`.** Enforce a round cap with `tool_choice`, never by dropping the tools.
- **Keep tool round-trips inside the turn.** Trimmed or rehydrated history that severs a call from its result poisons every request after it.
- **Fill arrives as recall, not as a reach** *(Orion)*. A plausible invention and a real memory have the same texture from the inside, so the texture cannot be the test.
- **A coverage metric defines the domain it measures** *(Orion)*. Measuring breadth against a list converts the list into the curriculum.
- **Spend a guardrail on the failure you cannot catch yourself in** *(Orion)*; trust is the right instrument everywhere else.
